# Node Bookmark Manager

**Node Bookmark Manager** is a lightweight Godot Editor plugin that lets you bookmark scene nodes for quick access during development.

## Features

- Add selected nodes to a persistent bookmark list
- Single-click to jump to a bookmarked node in the scene
- Remove bookmarks instantly with one click
- Fully integrated into the Godot Editor with a clean dock interface

## Installation

1. Copy the `addons/node_bookmarker` folder into your project's `addons/` directory.
2. In Godot, go to `Project > Project Settings > Plugins`.
3. Enable **Node Bookmark Manager**.

## Usage

- Open any scene.
- Select a node in the SceneTree.
- Click **"Add Selected Node"** in the plugin dock.
- It will appear in the list.
- Click any listed node to jump to it.
- Use **"Remove Selected Bookmark"** to delete it from the list.
